# E5：对应恢复与视觉状态纠错

本次目标是验证两件事：遮挡后是否能认回原来的身体点，以及关节读数发生偏差时视觉是否能纠正身体位置预测。原有 E4 模型、数据、评分和报告均保留，其他桌面物体与遮挡板保持固定。

## “反馈模型”是什么

更准确的名称是“关节反馈驱动的身体位置模型”：输入七个实际关节位置读数，输出 41 个固定候选点的三维位置。模型从 RGB 双目跟踪建立的训练对应中学习这个映射，不读取 CAD、仿真运动学或评价锚点。单次映射没有时间记忆；跨帧记忆与视觉关联由另一个明确的算法维护。

E5 冻结 E4 的空间网络和 V7 分割网络。新增多姿态 RGB 参考记忆和显式状态纠错，没有训练新的神经身份表示，也没有运行 CoTracker3。

## 数据和协议

- 视觉参考记忆只取 E4 中标为 `train` 的帧，按关节空间最远点采样保留 64 帧；同一特征的 ID 继承原始图像跟踪。有效参考须通过 V7 分割及 35 mm 的模型一致性检查。这个筛选可能继承原跟踪的错误。
- 开发集：种子 `2026102495`，140 帧。比较 7、11、21 像素光流窗口。7 像素恢复更多点，11 像素在偏差条件下误差更低；21 像素明显退化。最终选 7 像素、4 个最近姿态参考。
- 最终种子：`2026102501/2502/2503`，各 140 帧。配置、记忆、网络和六份相关源码的哈希在最终采集前冻结。每个预测文件完整保存并哈希后，独立评分器才读取评价标签。
- 正常读数与偏差读数使用相同的真实运动、RGB 和固定遮挡物。在第 26–30 帧逐渐给前三个旋转关节读数注入 `+0.055/+0.018/−0.015 rad` 偏移。算法收到的是偏移后的读数，不知道真实偏移、开始时刻或真实关节位置。
- 所有方案始终输出同样的 41 个候选点。空间误差始终覆盖其中全部 28 个物理身体锚点，包括丢失、被遮挡和从未重新观测到的点。
- 三种子为同一固定相机、固定路线的小姿态扰动，不代表跨场景或实机泛化。

## 方法

多姿态记忆按当前读数选参考，使用学习到的空间位置初始化光流，要求往返一致、外观误差、分割支持及真实双目匹配同时成立。空间先验本身不能成为“视觉测量”。

状态纠错从有效双目测量与冻结空间网络预测之间的残差，优化一个七维潜在输入偏移。网络的局部导数由数值差分计算，使用稳健加权、阻尼、步长限制和至少六个观测的支持门槛。随后用同一个空间网络预测纠正后的身体位置。比较项 `state_only` 不叠加逐点残差记忆，用来判断收益是否只来自局部贴补。

该偏移会混合编码器误差、网络误差与视觉误差，不能直接理解为精确的关节传感器标定，更没有证明能识别形态损伤。

## 三个新种子的结果

下表为全部身体点的三维 RMSE，按等长轨迹汇总平方误差后开方，单位 mm。

| 方案 | 正常反馈 | 偏差反馈 | 正常条件原点恢复 |
|---|---:|---:|---:|
| 只用原始关节反馈 | 9.741 | 24.123 | 无视觉恢复测量 |
| E4 原融合对照 | 9.801 | 21.401 | 6/81 |
| 多姿态视觉记忆 | 9.670 | 17.589 | 9/81 |
| 纠正状态后的网络预测，不叠加逐点记忆 | 10.305 | 10.208 | 无独立恢复测量 |
| 多姿态视觉＋状态纠错 | 10.233 | 10.120 | 10/81 |

偏差完全建立后的第 35 帧之后，原始反馈为 26.635 mm，原 E4 融合为 23.368 mm，完整新方案为 10.340 mm。故本次最有力的证据是视觉能够降低有偏反馈下的身体位置误差。正常反馈下，完整纠错方案比原始反馈退化约 0.49 mm，说明仍会把部分视觉或模型误差吸收入状态。

正常条件下，可见身体点的正确对应覆盖率按种子平均为：原 E4 33.03%、视觉记忆 53.56%、完整方案 53.72%。至少正确观测三次的身体点数平均从 13 增到 24.67/28。覆盖增加没有转化为可靠的快速重现恢复。

恢复沿用 E4 的固定标准：实际被板遮挡至少 3 帧，左相机重新看见后 5 帧内，接受的三维观测须在同一个物理表面锚点 20 mm 内。不会因预测接近真值便计为恢复。正常条件完整方案为 10/81（12.35%），偏差条件为 9/81。正常条件下，重现窗口内错误接受次数/全部接受次数为：原 E4 3/21、完整方案 2/24。分母很小，不能据此宣称错误率显著降低。

## 重新检查双目可观测性

主评分分母保持不变。完成预测后，另行渲染右相机深度，只用于诊断原来按左相机定义的重现窗口：81 个事件中，只有 25 个存在至少一帧双目同时可见；其余 56 个在原窗口内缺少双目同时可见的机会。这解释了部分失败，也提示后续应将“单目认回身份”和“双目更新三维位置”分别测量。

诊断没有删除这些事件，也不保证剩下的 25 个都有可辨识纹理。右相机检查以 15 mm 深度容差判断可见性；用七通道读数重放非驱动夹爪时，最大身体锚点差约 0.012 mm，已单独限制在 0.1 mm 内。诊断信息没有进入学习或预测。

## 验证与当前结论

完整 77 项测试通过，其中新增 4 项涵盖未知偏移纠正、缺失/严重错误视觉不更新状态、空白相机不能伪造视觉证据、姿态记忆预算。另用真实视觉记忆在 5 个最终姿态上输入空白双目图像，即使分割掩码全开，也没有接受任何视觉点或改变偏移。六份最终预测均通过哈希、41 点维度与有限值检查。桌面物体最大位移为 0。

本次证明的是局部仿真条件下视觉辅助状态纠错有用。持续身体身份仍未可靠建立；ID 延续、多姿态匹配、滤波更新是显式工程机制，不能称作神经网络已经学会物体恒存。没有测试实机、相机变化、无纹理重识别、未知形态变化或长期漂移。

可行性参考：[Full-Body Visual Self-Modeling](https://arxiv.org/abs/2111.06389) 展示从视觉学习身体空间表示与实机任务；[CoTracker3 官方项目](https://cotracker3.github.io/) 提供遮挡点跟踪的相关实现及失败案例。这些工作支持继续研究，不保证我们的当前方案能够解决全部目标。

## 复现与产物

在仓库目录中执行（需先恢复 E2/V7 与 E4 的附件）：

```powershell
python -m embodiment.recovery_cycle develop
python -m embodiment.recovery_cycle freeze --window 7
python -m embodiment.recovery_cycle final
python -m embodiment.recovery_report
python -m unittest discover -s tests -v
```

已有冻结协议会阻止重复冻结，已有预测会保留。全新独立复现应给 `recovery_cycle` 的各步骤指定同一新的 `--output` 目录；报告模块可导入 `make_report(Path(...))` 对该目录生成报告。
