# E12：可被观测推翻的动作先验与持续运动解释

执行前开发协议，2026-10-25。E11 的冻结结果完整保留。旧 E11 开发种子 2026103111 仅用于工程诊断；正式开发 2026103211，最终独立种子 2026103231、2026103232、2026103233。冻结前不得采集最终数据，全部最终预测封存后才能打开评价几何。

## 本轮变化

旧版要求动作预测也赞成才能纠错，健康反馈下执行受阻仍然失效。本轮并行维护开环命令、观测校正后的命令响应、维持上一次命令、速度衰减停止四条运动历史。当前反馈必须与事先预测的至少一条历史相容，并获得同一原始双目图像的表面支持；不再要求开环动作历史同意。连续确认后实际更新主状态及未来预测，保留未被排除的其他历史。候选包络不是概率置信区间，不声称完整联合似然建模。网络权重全部冻结。

反馈重获时速度除以实际观测间隔，避免将失联期间位移误当成单帧速度。单个突变读数不能建立它自己的确认历史。

## 数据、预算与对照

每个种子正常、持续受阻两条物理轨迹，每条180帧、0.1秒一步。沿用 E10 命令、固定干扰物、屏和相机；正常轨迹保留原60ms执行延迟。受阻轨迹30–149帧持续维持第29帧命令，150帧恢复执行。

这有意区别于 E11 在70/140帧同时恢复执行和传感器：现在70–109、140–149帧新观测已经恢复，但身体仍受阻，不能靠等待执行恢复冒充纠错。

十二种观测条件：旧七种、健康观测受阻、同输入运动/受阻配对、受阻叠加反馈偏差、受阻叠加相机缺失。传感器故障仍在30–69、110–139帧。前70帧配对全部输入精确相同，隐藏身体不同。两种新增交叉条件检验是否只是盲信反馈。模型不接收条件名、故障窗口、物理分支、评价真值。

相同82片段原始双目观测、434片段冻结身体图谱、28个固定实体锚点评分。重复初始化仅选一个实际匹配，不是多个独立来源。

七个方法：E12、冻结 E11（原校准、增益0、确认3）、E8B、同82片段的单状态表面纠错（增益0.2）、关闭 E12 观测推翻动作的消融、仅动作、仅反馈。所有方法同批输入比较；E12新结果不能直接与E11旧种子/旧受阻时长相减。

## 开发、选择与冻结

仅四组：连续确认2/3帧 × 关联门限倍率1/1.5。关联空间门限为开发正常动作—反馈99.5%分位与6mm取大；各关节归一化最大残差门限为99.5%分位与0.08取大。双目表面门限为开发健康正常及受阻读数残差99%分位与6mm取大。至少12片段。停止速度每步衰减0.5，速度限幅20倍身体尺度/秒。

选择损失为开发实际反馈状态教师的归一化均方误差：正常及健康受阻权重8、共同受损及协同回放权重4，其余1；不使用CAD评价几何。集合各关节余量取开发正常主状态误差及受阻配对第一窗口真实读数到最近事先运动候选的误差99%分位与0.02取大。不得由最终覆盖结果放宽。

源码、传递依赖、模型、协议、校准、开发选择及余量一起哈希冻结。最终三种子不调参；失败也报告。

## 预先验收与限制

1. 健康受阻30–149帧固定锚点RMSE相对同批 E11 改善至少70%；各正常轨迹回归不超过0.5mm；共同受损/协同回放宏误差相对同批 E11 不恶化超过3%。
2. 受阻配对两次新证据窗口70–109、140–149：身体构型在同一学习身体映射中相对实际读数距离≤5mm，且实体锚点误差≤健康反馈身体映射误差+2mm，连续5帧确认；每个事件应在1秒内完成。分别报告相对健康分支收敛，不能将收敛当成绝对正确。
3. 第一配对故障窗口，隐藏身体相距>15mm时未知≥90%、同一包络同时含两种实际七关节状态≥90%。正常未知≤10%；正常平均归一化半宽≤0.35。另报告最近实际运动候选误差，避免只靠放大外包络。
4. 证实观测推翻错误动作实际改变了主状态和后续预测，并比较关闭推翻的消融效果。

三种子只对应六条物理轨迹，十二条件与恢复事件共享数据，不能当成独立重复。当前仅仿真、干净初始化、已标定双目、已知七关节接口；持续120帧受阻和人为同步回放只是受控压力试验，不代表任意故障、完整身体身份或实机泛化。
