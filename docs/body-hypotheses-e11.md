# E11：相依证据、竞争身体解释与后续纠错

执行前协议，2026-10-25（Asia/Shanghai）。E10 的原模型与失败记录保留，本轮增加显式时序推断；不把这些机制称为新学会的神经故障分类。

## 主张

视觉跟踪借助动作／反馈初始化，同一 RGB 上的多次匹配和由其拟合的构型只算一个观测来源。保留受保护动作预测、当前观测支持、冲突前保持、上一状态递推等候选；证据不足时保持未知。新证据连续支持相容身体状态后提交状态更新并重置递推记忆；E9B表面匹配参与恢复条件检查，是否直接修正坐标取决于开发选择的增益，检验是否改善 E10 的恢复失败。

不承诺所有故障均可辨识。特意构造输入相同、隐藏身体不同的配对，以验证未知而不是强行选出唯一“真相”。

## 数据与对照

- 开发种子 2026103111；最终种子 2026103161 / 3162 / 3163，各180帧，动作采用冻结 E10 调度，0.1s步长。每种子正常与执行受阻两条物理轨迹。原有干扰物、固定屏及相机配置不变。
- 正常物理轨迹沿用 E10 两段60ms延迟；受阻轨迹在30–69、110–139帧保持此前命令，故障解除后恢复执行。机械臂会自身运动／停止，其他物体不动。
- 十种条件：E10七种短时传感条件、健康观测下的执行受阻、正常物理与受阻物理各自的协同回放配对。配对在两个窗口收到同一正常轨迹最初20帧的过去RGB及反馈。第一窗口结束前完整输入前缀完全相同，但隐藏身体不同；这属于受控合成不可辨识性试验，不宣称自然故障必然如此。
- 干预30–69、110–139；恢复70–109、140–179。模型不接收窗口、故障类型、物理分支标签、干净读数教师或评价几何。
- 所有旧网络冻结。新增双目表面观测从 E9B 已冻结的等预算82片段获取；动作与反馈可分别初始化同一RGB的匹配，重复片段只保留一个光度误差较低的实际双目测量。不能将两个初始化的匹配当作独立证据。
- 对照：E8B、同观测但没有多解释记忆的单状态表面纠错、简单多数相容候选、仅动作、仅反馈。单状态与多解释机制共用82片段与拟合器，避免把多拿视觉观测的收益冒充依赖处理收益。 单状态直接表面纠错固定为0.2增益，独立于E11所选增益；否则开发选中0增益时该对照会退化为原E8B。此说明在任何最终数据采集前补充，保留修订前协议与源码。

## 新推断机制与可调参数

候选都通过同一学习身体映射转换到空间。保留受保护预测和观测解释，显著分歧时不按“两路一致”删除另一路；另保留冲突前保持与递推状态，表达身体停止／执行异常的可能。候选集合代表多个可能身体表面，不填充中间区域为实体。

仅在反馈、表面匹配、动作预测与观测自身的逐步动态一致连续若干帧后提交恢复更新。几何拟合是有界显式最小二乘；确认恢复时更新状态及后续动作预测，并重置旧时序隐藏状态。记录每次显式更新，原融合权重不再等同最终状态的贡献。

正常开发数据的99%分位校准动作—反馈、表面残差与反馈动态残差门限。表面修正增益只比较0和0.2；连续确认帧数只比较3和5，共4候选，在开发轨迹选取后冻结。开发可用正常实际读数作为状态教师；不得用最终测试或CAD几何调参。此为推断参数选择，没有新增网络训练。

区间是候选包络加开发误差余量，属于可行集合而非90%概率区间。未知率、宽度、错误排除及准确性同时报告；不能以全部未知或无限扩张通过。

## 事先验收

1. **状态与正常保护**：最终正常每种子相对E8B锚点RMSE退化≤0.5mm；共同受损与协同回放的故障段宏平均至少改善5%。另报告仅动作与健康观测执行受阻，不能把动作永远正确作为前提。
2. **后续纠错与恢复**：相对同物理轨迹正常观测分支的身体预测距离连续五帧≤2mm；每条件至少5/6事件，成功中位确认时间≤1s。所有未恢复保留分母。另报告实际误差恢复，避免混淆。
3. **未知与候选保留**：配对第一窗口逐帧输出完全相同；在两隐藏身体确实相距>15mm的窗口，至少90%为未知，候选包络同时容纳两种真实关节状态的比例≥90%。同时列宽度和恢复后10帧的未知率，不把永久未知当成功。
4. **新增闭环的贡献**：与相同82片段的单状态纠错比较共同故障误差、恢复、错误确定性；记录实际表面修正／恢复提交，证明观测确实改变了状态和后续预测。消融不得只更改展示标签。
5. 所有三种子、全部条件、逐事件与逐帧结果公开。失败仍是有效结果，本轮不看最终分数后调参重用最终集。
