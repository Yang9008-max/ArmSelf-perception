# E6：动作、实际反馈与视觉更新同一个身体状态

用户认可“优先检验同一个身体表示是否真正连接动作、反馈和视觉”后，已完成第一轮训练与新数据评价。本轮的主要进展是补上了动作执行前的身体变化预测。完整融合还有明显不足；没有以遮挡点恢复率作为总目标。

## 实际实现

`embodiment/action_state.py` 新增动作转移网络。输入为当前关节位置、由过去两次读数估计的速度、动作命令目标和已知作用时长，输出未来关节位置。训练标签仅为动作执行后实际测得的反馈，没有使用仿真动力学、CAD 或几何真值。模型为两层 96 单元 MLP，另独立训练相同规模的无动作输入对照。

所有状态都通过同一个冻结的 E4 身体空间解码器输出 41 个候选点。融合流程先由动作预测状态，再以 0.9 权重吸收经偏移补偿的反馈，最后用 RGB 双目观测尝试修正同一状态。视觉更新要求至少 8 个有效对应、动作与反馈预测存在超过 8 mm 的空间分歧，且候选修正使这项分歧的平方误差降低至少 25%。偏移补偿与视觉关联均是显式算法。

内部状态坐标仍是人工定义的关节坐标，没有训练端到端的统一潜在身体表示。动作预测网络确实训练了新的权重；身体解码器、V7 分割及 E5 视觉记忆保持冻结。

## 数据隔离与时间顺序

- 训练：种子 `2026102601/02/03`，各 700 条转移，共 2,100 条。权重选择：独立种子 `2026102611` 的 350 条转移。各训练 650 个 epoch，并按验证误差选权重。
- 开发：`2026102621`，120 步，比较 8/14 mm 的视觉更新门槛。8 mm 的偏差反馈误差更低，正常和错误图像条件均未退化，选 8 mm。
- 最终：`2026102631/32/33`，各 120 步。配置、权重和源码在最终采集前冻结，正常条件允许的退化容差预先设为 +0.5 mm。
- 动作预测时间跨度为 20、60、120 ms。动作包括新目标、保持命令、反向命令。普通动作基准的预测文件在真实物理执行前写盘，随后才执行动作并读取未来反馈、RGB 与评价真值。
- 每个最终种子另有 12 组同状态不同动作试验，共 36 组。保存完整物理状态，分别从相同状态执行两条不同命令；两条命令的预测均先保存。
- 融合回放使用因果输入生成器：先提供命令，预测完成后才打开当前动作的执行后观测。所有融合预测保存并哈希后再评分。单元测试验证没有提前读取未来观测。
- 保留同样的全部 28 个物理身体锚点作为空间误差分母；丢点不降低评价分母。三件桌面干扰物位移为 0；本轮使用无遮挡基础场景。

## 动作后果预测

三个最终种子的等长轨迹汇总平方误差再开方，单位 mm。

| 方法 | 动作执行前的身体预测 RMSE | 同状态两种动作的结果差预测误差 |
|---|---:|---:|
| 学习动作后果 | 10.527 | 2.216 |
| 不输入动作 | 20.066 | 18.069 |
| 保持当前位置 | 22.654 | 18.069 |
| 直接将命令目标当成到达状态 | 43.847 | 39.210 |
| 错误配对动作 | 36.183 | 36.384 |

正确动作在三个种子上均优于无动作输入和目标即状态的对照；同状态配对进一步支持模型学到了局部动作对身体变化的影响。结果仅覆盖同一机械臂、固定相机和局部命令范围，没有证明跨形态或跨动力学泛化。

## 同一状态的观测更新

全部数字为身体位置 RMSE（mm）。各条件使用相同的物理轨迹，只有观测通道的干预不同。

| 方案 | 正常 | 反馈偏差 | 反馈延迟 | 相机中断 | 错误图像 |
|---|---:|---:|---:|---:|---:|
| 仅实际反馈 | 10.346 | 24.596 | 21.222 | 10.346 | 10.346 |
| 仅动作递推 | 10.566 | 10.566 | 10.566 | 10.566 | 10.566 |
| 动作＋反馈 | 10.347 | 24.002 | 19.969 | 10.347 | 10.347 |
| 动作＋视觉 | 10.077 | 10.077 | 10.077 | 10.207 | 29.001 |
| 反馈＋视觉（无动作） | 10.441 | 11.179 | 20.949 | 10.441 | 22.873 |
| 动作＋反馈＋视觉 | 10.347 | 12.270 | 13.120 | 10.347 | 10.347 |

所有模式获得一次干净的初始反馈。“仅动作递推”和“动作＋视觉”随后不读取新反馈；在读数偏差和读数延迟条件下，其输出与正常条件逐元素相同，已验证。

完整方案在正常条件下与仅反馈的误差差约 +0.001 mm，三个种子均在预定 +0.5 mm 容差内。这不是统计非劣效性检验。

视觉确实降低了偏差/延迟反馈分支的误差，但完整融合仍不如仅动作递推，更不如使用正常图像的动作＋视觉。原始融合对反馈的信任过强，改进传感器可靠性判断比继续提高遮挡点恢复率更直接关联本轮缺口。

## 不能夸大的部分

- 正常及错误图像条件下，完整方案均为 **0/360 次视觉更新**。其稳定性来自显式规则阻止视觉修改状态，不能称为网络学会识别了错误图像。偏差反馈条件为 12/360 次更新，反馈延迟条件为 219/360 次。
- 动作＋视觉在正常条件有效，但错误图像将误差提高到 29.00 mm；没有动作输入的视觉融合也退化到 22.87 mm。传感器并非越多越好，需要判断相互矛盾的信息。
- 每条轨迹第 90–99 步加入预测器未知的 20 ms 执行延迟。在该区间，正常传感器条件下仅动作递推为 11.597 mm，完整融合为 10.198 mm。反馈对未预料到的执行变化有帮助，但该故障范围有限。
- 暂未组合错误反馈与错误图像，没有长期漂移或实机试验，也没有校准状态不确定性。缺失视觉时明确无视觉证据，但这不等于具备已校准的不确定性表示。
- 41 个候选点只是第一轮受控测量接口；28 点空间评分不能证明完整身体形态、部件关系或持续身份已学成。
- 三种子属于同一仿真设置和同类随机动作协议。学习到的动作后果与视觉更新机制尚未端到端联合训练。

## 验证与复现

84 项完整回归测试通过，含 7 项新增测试：预测先于未来观测读取、状态更新顺序、视觉修正冲突反馈、错误视觉不覆盖一致的动作/反馈、缺失视觉不制造支持、无反馈模式独立于新读数、无动作模型独立于命令。

报告生成时核验 396 份动作前预测文件（360 个顺序动作和 36 组配对）、15 份融合预测、所有冻结源码哈希、全部 41 点有限输出和相机缺失区间的零视觉支持。

```powershell
python -m embodiment.action_cycle develop
python -m embodiment.action_cycle freeze --gate 0.008
python -m embodiment.action_cycle final
python -m embodiment.action_report
python -m unittest discover -s tests -v
```

已有文件会保留，已有最终协议不允许重复冻结。独立复现可为 `action_cycle` 各步骤指定相同的新 `--output` 目录，并通过导入 `action_report.build(Path(...))` 对新目录生成报告。重新开始时的模型权重仍来自文中固定 E4/E5 依赖。

输出位于 `outputs/local-check-20261024/e6-action-body/`。关键文件包括训练转移、`training-freeze.json`、`final-protocol.json`、`data-*/before/`、`data-*/after/`、隔离的 `evaluation/`、`paired-*/`、`predictions/`、`scores/`、`test-result.json`、`validation.json` 和 `report/`。
