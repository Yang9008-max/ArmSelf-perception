# E10：身体表示在冲突、未知与恢复中的独立验证

执行前协议，2026-10-25（Asia/Shanghai）。本轮回答用户确认的问题：动作预期、反馈与视觉冲突时，统一身体表示是否有助于排除错误解释、保留不确定性，并在新证据出现后恢复。

## 主张与边界

冻结 E8B 状态模型、动作模型、旧视觉前端及 E9B 的 434 片段表面解码器，不重新训练。首先检验已有能力，允许结果否定主张。额外的身体一致性审计是显式诊断读出，不是模型新学会的故障识别，也不偷偷改变 E8B 状态。

审计比较三个候选解释：独立动作递推、实际反馈、RGB 前端给出的构型；通过同一 E9B 图谱转换成身体表面，比较几何一致性。相同候选另做归一化关节距离审计，以及无时间平滑的几何审计。这样检验几何表示是否优于仅有关节残差。RGB 前端依赖动作初始化，不能把两个同意者当作两份独立证据；离群仅说明不一致，不证明谁故障。

## 数据与干预

- 开发种子 2026103011；最终种子 2026103031 / 3032 / 3033。均为新轨迹，180 帧、每帧 0.1 s。开发用于正常残差门限，最终数据在协议和代码冻结后采集。
- 原有桌面干扰物完全固定，沿用既有固定遮挡屏；无相机或形态改动。
- 每条物理轨迹有两个未知执行延迟窗口：50–74、110–134 帧，延迟 60 ms；正常条件也含这些窗口，称“传感器正常”，不称物理执行无误。
- 反馈／RGB 干预窗口为 30–69、110–139 帧；恢复窗口 70–109、140–179。80–99 帧停止命令，检验恢复不只依赖持续运动。
- 七种传感条件：正常、短时反馈偏差、过去 RGB 回放、二者同时发生、反馈缺失、相机缺失、反馈与 RGB 协同回放过去的同一个状态。最后一项检验两个受损通道相互同意时的错误确定性。
- 回放只用最初 20 帧的过去数据。干预标签、窗口、偏差量、干净读数和评价几何均不进入估计／审计接口；缺失标志作为传感器可用性输入。错误图像不附送陈旧时间标签，因此不是测试时间戳检查器。

## 对照与输出

E8B 完整、E8B 去视觉、E8B 去反馈、仅动作、仅反馈（缺失时动作递推）、固定等权。去视觉／反馈仅在更新器屏蔽输入；共享视觉前端保持不变，不能称完全移除动作或纯视觉。

保存执行前预测、更新后状态、七关节权重与原有校准区间；三种审计输出一致／候选不一致／多解释未决／信息不足，不把离群判定等同故障概率。冲突时另报涵盖所有可用候选的区间包络，明确它是保守集合而非概率区间，并同时报告宽度，防止以无限扩张冒充可靠性。

所有模型统一通过同一解码器；固定物理锚点始终保留共同分母，并报告 E9B 全部片段的离体比例。审计只使用模型与观测，不读评价真值。

## 冻结判据与分析

1. **状态纠错收益**：四个错误观测条件（偏差、回放、共同受损、协同回放）宏平均锚点 RMSE 相对等权至少改善 10%；正常相对仅反馈每种子不退化超过 0.5 mm。分别列出全部失败。
2. **识别与排除**：干预窗口检测 F1、正常误报率、离群解释确实错误的精度及判定覆盖。另按候选几何误差大于 8 mm 定义“有实质影响的错误解释”诊断，区分发生了干预与干预真的影响候选。离群错误精度目标 80%，必须同时报告覆盖，不能靠全部未知通过。
3. **保留未知与不确定性**：原 E8B 名义 90% 同时七关节区间逐条件覆盖；低于 85% 记为可靠性失败。显式包络另列覆盖与归一化半宽，不能继承 90% 概率含义。协同回放单列错误离群判定；不声称有观测上不可辨识问题的唯一解。
4. **恢复**：故障结束后，与同一物理轨迹正常分支的身体预测距离连续五帧 ≤2 mm，记为收敛恢复；同时锚点 RMSE 连续五帧 ≤正常分支 +2 mm，记为实际误差恢复。40 帧内未恢复保留为删失，不能只平均成功案例。目标每条件至少 5/6 事件恢复，成功事件中位时间 ≤1 s；这是工程验收要求，不是通用科学阈值。
5. **身体表示的额外价值**：几何审计与归一化关节审计按各自正常开发残差第 99 百分位定门限，固定 2/3 帧时间平滑。几何检测 F1 比关节审计高至少 0.05 且正常误报 ≤5%，才称本轮有支持几何表示额外收益的证据。无平滑审计显示时间机制的作用。

检测干预并不等于识别故障来源；当前读出没有学习来源概率。几何错误指标用解码器在真实状态与候选状态下的差异，仅用于评价候选状态的影响，不等同完整表面真值。

## 复现与防泄漏

开发阶段只用正常观测分布校准门限，不用最终结果改规则。冻结输入模型、协议与推断源码哈希后再收集最终轨迹。全部最终条件预测保存并封存后才打开评价几何和干净反馈评分。保留逐帧、逐种子、逐事件数据、失败与审计记录。模型若不达标，本轮不临时调参重测同一最终集。

结果完成后补充到独立总结和本地动态报告；原 E4–E9 冻结模型和记录保持原样。
