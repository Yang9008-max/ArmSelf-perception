# 同一身体表示中的动作、反馈与视觉

本文件是 E6 的阶段协议。E7 后确认的整体研究目标、三个核心问题与可靠性要求见[课题定义与验收框架](research-definition.md)。

状态：用户确认主线后，第一轮 E6 已执行，见 [E6 方法、结果与边界](action-body-e6.md)。下文保留执行前的代码审计与验证原则；实际冻结配置、完成范围及尚未完成的部分以 E6 记录为准。已有 E4/E5 结果保留原结论。本次记录不将遮挡点恢复率提升视为整个项目的主目标。

## 核心问题

同一个身体状态表示能否完成以下过程：依据过去的观测与即将执行的动作预测身体变化；动作执行后，使用实际反馈检查预测；再用视觉提供独立证据，修正状态或识别不一致。

“同一个表示”要求预测与更新指向同一身体状态，并通过同一身体解码器输出可比较的身体量。分别训练几个互不联系的任务、展示三个输入通道，均不构成通过。首先可用可解释的状态和现有空间解码器建立对照；若包含人工定义的状态、显式关联或滤波，必须注明，不能称为已学得统一的神经身体表示。

## 第一项决定性实验：提前预测动作后果

记录每次动作之前的实际反馈、可用 RGB、历史状态、动作命令、作用时长，以及执行后的实际反馈和 RGB。所有通道保持明确时间戳。

模型在动作执行前固定预测，输入仅包括当时可知的历史和动作。随后执行动作，保存预测，再读取未来观测及独立评价真值。未来实际关节读数不能进入“提前预测”的输入。

使用相同起始状态、不同动作的配对试验，比较模型是否能预测不同的身体变化；同时覆盖保持、反向动作和动作响应延迟。命令目标与实际到达姿态分别记录。

对照包括保持当前状态、把命令目标直接当成到达状态、去掉动作输入，以及错误配对动作。错误配对只检查依赖性；真正正确的动作必须改善新轨迹上的提前预测，才能支持动作输入有用。由于局部伺服响应可能很简单，必须报告“目标即状态”这个强对照。

## 第二项实验：观测更新同一预测状态

对同一组动作轨迹，依次保存执行前的动作预测、实际反馈更新后的预测、视觉更新后的预测。各阶段使用同一解码器和相同评价对象，分别报告更新的增益和退化。

条件至少包括正常观测、有偏或延迟的实际反馈、相机缺失，以及与当前姿态不一致的图像。错误图像须与正常图像配对，检查视觉证据是否被拒绝，避免将任何图像差异直接解释为身体变化。时序打乱与跨姿态错配属于离线诊断，不能等同于真实传感器故障的完整分布。

用去掉视觉、去掉反馈和去掉动作的对照检查每种信息的作用。仅有打乱输入后变差还不充分；正确输入应带来可复现的预测或状态更新收益。缺失时须保留状态，并表达信息不足，不能把模型自身预测重新当成视觉支持。

## 评价与边界

- 开发、参数选择和最终评价按轨迹分离，冻结配置后采集最终数据；逐种子报告。
- 主指标是提前预测误差、各观测阶段对同一状态的更新增益，以及冲突/缺失条件下的退化。先报告基本事实，再决定具体优化方向。
- 正常条件不退化的容许范围、预测时间跨度与最低有效观测覆盖应在最终评价前确定。不能观察最终结果后再调整阈值。
- 现有 41 个候选点可作为第一轮受控测量接口，身体锚点始终保留共同分母。它们不能代表完整身体形态，不能因局部点误差低便宣称形态学习完成。
- 视觉关联数量、覆盖率和错误接受作为诊断指标。遮挡测试进一步检查状态维持、图像身份关联和三维重新测量，各自报告。
- 原有桌面物体保持固定。动作命令、实际反馈和 RGB 可以输入；CAD、身体几何身份、仿真深度及物理锚点仅供隔离评价。

第一轮要回答的是“现有表示的哪一条联系已得到证据，哪一条尚未建立”。动作预测缺失时先补这条联系；不能继续只优化遮挡点跟踪而将其收益当作完整身体感知的进展。
