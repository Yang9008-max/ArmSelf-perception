# R1 真机先导实验：从自身运动建立身体认识

日期：2026-10-25。状态：方案草案，未连接硬件、未采集真机数据、未训练或运行真机模型。用户尚未确定设备；本方案不预设机械臂型号、通道数量、厂商 SDK 或相机型号，不涉及采购建议。E13 及更早实验保持原样。

## 目的与结论边界

首轮回答：在真实图像、实际执行误差和异步观测下，自身动作及反馈是否能帮助模型发现可见身体，并预测身体的后续变化？

真机不是有效性的自动证明。把仿真画面换成相机视频、显示机械臂掩膜，或读到关节位置，都不能单独证明通过运动建立了身体认识。首轮不以抓取、复杂故障识别、完整网格或接触辨识作为前置条件。

现有仿真的作用转为保留可复现对照和排查推断错误；新的主要证据来自独立真机采集。不会把仿真的毫米误差、阈值和冻结权重直接当作真机结果。

## 按可用观测限制问题

| 能力组合 | 首轮能够验证 | 不能仅凭这些数据宣布 |
|---|---|---|
| RGB 与图像时间 | 视觉运动、可见区域和二维跟踪 | 动作引起的身体归属、可靠三维定位 |
| RGB、实际下发动作、实际位置反馈及各自时间 | 动作条件下的可见身体发现、二维变化与反馈预测 | 任意视角下的完整身体、三维实体范围 |
| 上述信息与经过校准的双目或深度测量 | 可见身体三维点、空间预测与纠错 | 不可见部位的完整形态、体积及接触物理属性 |

三维评价还需独立的尺度和几何参照；用同一个学习身体解码器产生预测和答案，只能检查内部一致性。若仅有 RGB，第一阶段明确以二维任务验收，不用模型自己推测的深度制造毫米指标。

## 一次有边界的采集

设备确定后，再根据实际可执行范围定义动作；本草案不生成或下发控制命令。先记录静止片段、分通道局部动作、组合动作，以及停下再启动的连续片段。保留正常光照、阴影和真实漏帧，不因视觉匹配困难而删除失败片段。环境干扰物保持固定。

每条序列独立保存：

- 原始图像、相机 ID、曝光时间（若能取得）、主机接收时间、帧号和缺失标记。
- 请求动作、实际下发动作、下发时间、单位与控制模式。
- 设备实际读回位置、读取时间、设备时间（若能取得）、通道有效性及校准信息。
- 通道列表、采集软件版本、时钟来源、可获得的延迟信息。没有测到的量保持缺失。

动作目标不能代替实际位置。相机和总线先后读取的数据不能当成同时测量。若设备不能提供曝光时间，应报告时间精度限制，而不是补写虚构的时间戳。

## 两个核心检验

### A. 运动是否帮助发现可见身体

从训练序列中的动作、反馈和视觉变化建立身体候选，不向发现算法输入人工身体掩膜、部件标签或 CAD 身体身份。模型可知通道编号和单位。

在独立保留序列上，对少量事先抽取的帧人工标注活动身体及阴影、反射和背景。标注只用于评价，不用于选择发现门限。分别报告身体纯度、覆盖率、两者的权衡及阴影／背景误收；只删去困难点提高纯度不算成功。

至少比较：纯视觉运动方法、真实对齐的动作／反馈方法，以及结构相同但破坏跨模态时间对应的方法。错配对照应尽量保持动作幅度和单模态时间结构，避免靠明显异常输入制造优势。用停下和重新运动的片段检查是否只是逐帧运动检测。

固定环境下的成功只支持该范围内的可见活动身体归属，不证明能排除任意独立运动物体。停下后能保留区域也不自动证明完整持续身份。

### B. 动作是否帮助预测实际身体变化

在读取未来观测之前，保存给定历史和当前动作的未来反馈、可见身体点或图像运动预测。评价时使用真实未来反馈及独立人工可见点标注；遮挡点按预先约定的规则单列，不能用预测值补成真值。

至少比较保持当前位置、基于历史反馈的速度外推、无动作的同结构预测器及有动作预测器。动作目标可以作为额外简单对照，但不能当作未来实际状态。

按明确预测时距报告位置或像素误差、逐轨迹结果及简单基线差值。首轮正常数据有效后，才考虑观测缺失与状态纠错；不先移植全部 E13 故障规则。

## 数据隔离与停止条件

按完整采集序列或场次划分训练、开发和最终测试，不能随机拆相邻帧。新轨迹与新场次分别报告；前者不能冒充相机、形态或场景迁移。开发后冻结模型、预处理和评价，再采集或解封最终数据。

具体轨迹数、采样与预测时距、允许退化和收益门限，要在设备及开发噪声尺度明确后预先确定；本草案不承诺采集时长、毫米精度或成功比例。时间帧和同一轨迹的多个处理版本不算独立物理重复。

若身体发现不优于纯视觉运动，先检查动作与反馈的额外价值；若动作预测不优于无动作和速度外推，先检查数据对齐及响应学习。此时停止堆叠复杂融合规则，记录失败原因。

通过先导实验后，下一问题才是：在相同输入、数据和评价下，共享身体几何是否比强状态估计基线更有用。先导成功不等于已经回答该问题。
