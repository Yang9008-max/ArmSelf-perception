# E8B：加强正常保护与反馈缺失条件的第二轮优化

## 执行前协议

E8A 已完成并冻结，报告保存在 `outputs/local-check-20261024/e8-reliable-state/report/`。第一轮相对同批新数据上的 E7，在反馈偏差下改善 11.54%，但错误图像只改善 4.94%，且正常保护检查未通过。反馈缺失时七关节区间覆盖仅 68.67%。这些失败用于提出第二轮假设，原始最终轨迹不进入第二轮训练或轮次选择。

第二轮保持身体、动作、分割、视觉前端和网络结构不变，针对损失与训练分布做调整：

| 参数 | E8A | E8B | 检验目的 |
|---|---:|---:|---|
| 候选贡献辅助监督系数 | 0.03 | 0.10 | 加强对真实候选误差的区分 |
| 逐关节候选误差温度 | 0.0001 | 0.00001 | 减少正常时精确反馈与较差候选之间的模糊监督 |
| 每轨迹正常序列重复数 | 3 | 5 | 增加正常保护的训练权重 |
| 每轨迹无反馈序列重复数 | 1 | 3 | 增加反馈缺失条件的训练权重 |
| 开发选择额外正常损失系数 | 3 | 8 | 优先选择正常条件退化较小的模型 |
| 训练轮数 | 160 | 180 | 在同一轮次预算下比较两个候选 |

训练仍是相同六条轨迹的 720 个独立物理步骤，增强／重复序列从 126 增至 150，重复不构成新数据。仍分别训练有／无偏差状态的两个候选，只依据两个开发种子 `2026102711/2811` 选择。开发种子固定，重新渲染不算新增独立场景。

独立校准使用新种子 `2026102851`；模型及校准冻结后，最终采集新种子 `2026102861/2862/2863`。E7 及 E8A 的最终轨迹均不作为本轮训练／选模数据。所有最终预测保存并哈希后才打开几何评分。

原 E8A 的验收目标不降低：错误图像相对同批数据上的冻结 E7 改善至少 10%，反馈偏差改善至少 5%；每个种子的正常误差相对仅反馈不超过 +0.5 mm、相对 E7 不超过 +0.3 mm。其他条件退化、逐种子差异、90% 区间覆盖与宽度全部报告。

最终报告将区分首轮失败和第二轮结果，不把不同最终轨迹的绝对误差直接排名，也不会用最终测试结果重新挑选两个候选。

## 开发阶段实际配置

两版本均完成 180 轮训练，实际使用 150 条重加权序列。开发选择不启用偏差状态的 `per_joint` 第 165 轮，选择分数 0.031721；偏差状态候选第 111 轮，分数 0.097901。该分数使用不同于首轮的正常权重，不应与首轮选择分数直接比较。

模型选定后，新校准轨迹得到名义 90% 同时七关节状态区间的尺度因子：所选版本 5.03584，偏差状态候选 5.58431。校准不反向修改状态模型，区间不涵盖身体解码器的几何误差。

本轮新增模型脚本为 `embodiment/reliable_cycle_v2.py`，核心时序网络继续使用冻结的 `embodiment/reliable_state.py`。E8A 源码与模型保持其冻结哈希，避免后续修改覆盖实验历史。

## 最终结果

已完成冻结后的三个新种子、450 个物理步骤及八条件评价。七个条件优于同批重跑的 E7；错误图像改善 12.94%，反馈偏差改善 13.32%，正常保护按三个种子均通过。共同故障从 E7 的 14.823 mm 升至 15.781 mm，是明确退化；90% 七关节区间总体覆盖90.11%，无反馈条件只有77.78%。

参数、训练变化、逐条件结果、强基线与失败原因统一见[两轮优化完整总结](model-optimization-e8-summary.md)及[最终详细报告](../outputs/local-check-20261024/e8b-reliable-state/report/详细优化报告.md)。
